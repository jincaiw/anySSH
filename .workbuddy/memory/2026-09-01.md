- 过程中发现并修复两个真实缺陷：
  1. `@types/node` 从未声明为直接 devDependency——i18n 代码引用 `process`/`node:fs`，本地靠偶然传递解析通过，容器全新安装后 tsc 报 TS2307/TS2580。修复：显式声明 + 更新 lockfile（提交 `5f496fd`）。教训：i18n-parity 静态扫描应同时检查组件 key 是否存在于目录，且新增 node API 引用必须显式声明类型依赖。
  2. **E2E 测试机从未设置 `ANYSCP_UI_LANG=en-US`**——Rust 端覆盖逻辑存在但 harness 没接，容器以 zh-CN 默认跑，首轮 30/101 个英文选择器全挂（报错里出现中文文案）。修复：compose 给 runner 加 `ANYSCP_UI_LANG: "en-US"`（提交 `0573b9c`）。教训：跨端契约（Rust 注释声称容器设置）必须有一端真正落地。
