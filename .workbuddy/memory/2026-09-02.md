## 修复 "Authentication failed: server rejected credentials"（commit 94eed4d）

- 根因一：russh `authenticate_password` 只发 `password` 方法，网络设备/加固 sshd 常只允许 `keyboard-interactive`。
- 根因二：russh-keys 对 RSA 密钥固定用 rsa-sha2-512 签名（`decode_openssh` → `SHA2_512`），老设备只认 rsa-sha2-256 甚至 `ssh-rsa`(SHA-1)。
- 修复（manager.rs）：密码认证失败后回退 keyboard-interactive（所有 prompt 用密码作答，上限 8 轮）；RSA 公钥认证失败后按 SHA2_256 → SHA1 重签重试（`KeyPair::with_signature_hash`）。终端/SFTP/SCP/健康检查/ProxyJump 全部经 `authenticate_handle` 生效。
- 验证：cargo test 214/214、clippy 干净；已推送 jincaiw/main（CI 触发）。注意 git 提交者身份是自动生成的 jason.wa@jincaideMac-mini.local。
