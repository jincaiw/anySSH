## Windows WebView2 离线打包（v0.14.10）

- 需求：Windows 安装包内置 WebView2 运行时，不再安装时在线下载。
- 实现：tauri.conf.json 新增 `bundle.windows.webviewInstallMode = { "type": "offlineInstaller" }`（commit `a550b45`，rebase 到远端 v0.14.9 之上）。生效范围：NSIS（x64-setup.exe）与 MSI，安装器体积约 +127MB。
- **portable zip 无法内置 WebView2**：Tauri 便携包不含安装器逻辑，运行时仍需系统自带（Win11 内置；Win10 大多数已装）。需在 release notes 说明。
- 推送时发现远端领先（另一会话的 v0.14.8/9），rebase 后重推；教训：多会话并行工作时推送前先 `git fetch` 看分歧。
- v0.14.10 发布成功：setup.exe 9MB → 258MB（WebView2 离线运行时已嵌入，体积验证生效）。构建首轮 Linux job 在 tauri-action 上传末尾撞 GitHub API "Not Found - delete-a-release-asset"（8 资产已传完、仅剩 portable 步骤没跑），rerun --failed 即恢复；`gh release view --json assets` 对比 v0.14.9 体积确认打包成功。已发布 Latest，端点返回 0.14.10。
