## 终端编码切换下拉智能翻转（2026-09-03 14:35）

- 用户反馈：终端右下角编码切换框（EncodingSwitcher，`absolute bottom-2 right-2`）下拉向下弹出，贴近窗口底边不好选。
- 根因：CustomSelect `computePos()` 恒定 `top: rect.bottom + 4`，从不判断视口剩余空间。
- 修复：CustomSelect 加 useLayoutEffect 翻转逻辑——列表挂载后测 `offsetHeight`，下方空间不足（`spaceBelow < listH + 8`）且上方空间更大时翻转为 `top: rect.top - listH - 4`（clamp 8px）；`flipDoneRef` 防循环，openDropdown 时重置。绘制前翻转无跳动；通用修复，所有底部锚定下拉受益。
- 验证：tsc 干净、vitest 133 绿（jsdom rect 全 0 时 spaceBelow=768 不触发翻转，测试不受影响）；e2e 因 Docker 未运行未执行，需后续 `make e2e` 补验（spec 66 编码切换）。
- 补验完成（15:00）：无需本地跑——该提交的 main CI 33724379377（含 E2E 四分片）已绿，与 `make e2e` 等效，遗留项关闭。
