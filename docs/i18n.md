# anySSH 多语言（i18n）指南

anySSH 的前端文案全部走 `src/i18n`。当前内置 **简体中文（zh-CN，产品默认）** 与 **English（en-US）**。

## 运行时

自己实现、无第三方依赖（项目已有 zustand），只提供：键查找、`{name}` 插值、CLDR 复数、持久化。

```ts
// 组件内（响应式，切换语言会重渲染）
import { useTranslation } from "../../i18n";
const { t } = useTranslation();
t("explorer.toolbar.refresh");

// 组件外：store / hook / util（非响应式，toast、错误文案等）
import { t } from "../../i18n";
t("sftp.toast.uploadStarted", { name: "a.txt" });
```

其它入口：`useI18nStore`（语言选择器用）、`translateIfPresent()`（键缺失返回 `null`）、
`localizeBackendError()`（后端错误本地化，见下）。

## 目录结构

```
src/i18n/
  index.ts              运行时、store、t / useTranslation
  catalog.ts            各语言目录汇总
  types.ts
  locales/
    en-US/
      index.ts          命名空间 → 加前缀合并
      common.ts  errors.ts  settings.ts  dashboard.ts …
    zh-CN/ …            与 en-US 逐键对应
```

命名空间文件里的键**不带**命名空间前缀，`index.ts` 统一加（即 `settings.ts` 里的
`appearance.title` 最终是 `settings.appearance.title`）。

## 词条规则

1. **两份目录必须逐键对应**。`npm run i18n:check` 校验，缺键直接失败。
2. **en-US 是 E2E 契约**，不得改写。`tests/e2e/specs/*.spec.ts` 按可见文本选择元素，
   改一个标点就会挂一堆用例。想改英文文案请单独提 PR 并同步改用例。
3. **en-US 同时是兜底**：任何语言缺键都回退到英文，而不是显示裸键。
4. 共享词（取消/保存/删除/名称/大小…）先查 `common.*`，已有就复用；
   需要新共享词且只有你用到 → 放自己的命名空间，不要动 `common.ts`。
5. 复数：键加 `_one` / `_other` 后缀，插值传 `{ count }`。
   zh-CN 只会命中 `_other`，但两个后缀都要写。

## 语言选择顺序（首次渲染）

1. Vitest → 强制 `en-US`（单测断言英文；产品默认是中文）
2. `<html data-lang>` —— Rust `setup()` 首屏前注入，承载持久化选择 + `ANYSSH_UI_LANG` 覆盖
   （E2E 容器设为 `en-US`，这样 WebdriverIO 用例无需改动）
3. localStorage `anyssh.locale`
4. 系统语言：`zh*` → 中文，`en*` → 英文
5. 兜底 `zh-CN`

用户在 Settings → Appearance → Language 切换后写入后端 `app_language` 设置项。

## 后端错误本地化

Rust 不翻译。每个错误枚举都序列化成 `{ kind, message }`，前端把 `kind` 当翻译键：

- `errors.<kind>` 给出本地化前缀
- `message` 里 `: ` 之后的**技术细节原样保留**（`Connection refused (os error 61)` 这类
  保留英文更利于排障）
- `kind` 未登记 → 直接回退后端原始英文，不显示裸键

新增 Rust 错误枚举时，同步往 `locales/*/errors.ts` 补 `kind`。

## 不要翻译的东西

- `data-testid`、`aria-keyshortcuts`、CSS 类名、图标名
- 键盘事件键名：`Escape` / `Enter` / `ArrowDown` / `k` …
- Rust 传来的状态与类型判别值：`Queued` `InProgress` `Completed` `Failed` `Cancelled`
  `Connected` `Connecting` `Disconnected` `Active` `Starting` `local` `remote`
  `password` `privateKey` `local`/`remote` …
  （这些要显示给用户时，在你的命名空间里写 `statusLabel()` 做映射，未知值回退原始串）
- 字体名、编辑器名（`VS Code`）、厂商/服务名（`Amazon S3` `MinIO` `Cloudflare R2`）
- 传给 `invoke()` 的参数、shell 命令、文件路径、扩展名
- 代码片段里的 `{{variable}}` 占位符（与 i18n 的单花括号插值互不影响）

## 校验

```bash
npm run i18n:check   # 中英词条逐键比对 + 未使用键提示
npm run typecheck    # tsc --noEmit
npm test             # vitest
```
