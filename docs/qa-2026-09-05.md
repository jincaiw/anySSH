# 功能修复与桌面体验验收（2026-09-05）

本轮按照已确认的评估方案实施，重点覆盖近期新增的本地终端、Telnet、串口、VNC、RDP 及其保存、编辑、重连流程。本文记录本轮修复及后续首页调整，发布验收结果见文末。

## 已完成的修复

| 范围 | 问题与修复 |
| --- | --- |
| 本地终端 / Telnet / 串口 | 注册缺失的 `TermManager`；终端输入、调整尺寸、分屏、代码片段、手动日志和重连按协议调用对应后端。 |
| 终端首屏 | 输出订阅建立后才启动读取，避免欢迎横幅或短命进程的首批输出丢失。 |
| 本地终端 | 设置 TERM 与默认工作目录，检查显式目录，关闭时终止并回收 Shell 子进程。 |
| 串口 | 关闭和析构时通知读取线程退出；关闭接收队列并等待线程，修复空闲超时循环泄漏；禁止同时分屏打开独占串口；修复热插拔订阅的异步卸载。 |
| VNC | 处理服务器凭据请求并提交用户名/密码；修正 `clipboardPasteFrom` 接口；非活动标签页不再读写本地剪贴板；处理组件加载失败。 |
| RDP 画面 | 在注册 ready 事件后挂载组件；连接成功后显式显示画面，切换标签时同步可见性；复用 WASM 初始化。 |
| RDP 剪贴板 | 通过原生插件处理文本剪贴板，提供粘贴按钮和 Ctrl+Alt+Del，避免依赖 WKWebView 中不可用的浏览器剪贴板。 |
| RDP 证书 | 首次连接检查并显示 SHA-256 指纹，明确确认后保存；证书变化要求重新确认；实际 TLS 连接再次核对指纹，并验证握手签名。 |
| 远程桥接 | 避免 JoinHandle 完成后再次 await；取消另一方向的转发任务，确保释放活动会话；串行初始化监听器；为握手设置超时和取消路径。 |
| 主机保存 / 编辑 | 统一非 SSH 协议编辑器，避免误入 SSH 表单；编辑后的地址、端口与实际连接参数保持一致；保留主机 ID、分组、备注和编码。 |
| 数据库兼容 | 将缺失的日志预设按 false 写入，修复新协议主机保存触发非空约束的问题。 |
| Telnet 脚本 | 整段脚本存入已有加密凭据库，主机 JSON 只保留引用；读取旧主机时迁移旧格式；复制书签时复制凭据引用对应的数据。 |
| 连接历史 | 最近连接和历史记录按协议重连，禁用非 SSH 的文件浏览入口；SSH 后端拒绝误传的其他协议书签。 |
| 图形连接保存 | VNC/RDP 在认证成功后保存书签和记录连接，避免仅创建桥接令牌就保存；RDP 编辑重连保留原书签 ID。 |
| 桌面布局 | 按后续确认方案直接显示本地终端、SSH、Telnet、RDP、VNC、串口、对象存储；统一描边按钮并允许整项换行，管理操作移至主机标题旁。 |
| 对话框 | 新协议共用弹窗样式、字段标签和操作区；长脚本内容可滚动，标题和按钮固定可见；补充焦点约束、恢复和 Escape 行为。 |

## 验证边界

- 串口使用虚拟终端对验证收发、取消和线程回收；当前没有物理串口适配器，未验证拔插实物、驱动或电气参数。
- RDP 已验证组件显示逻辑、认证失败路径、TLS 回环、证书确认和指纹变更拒绝；当前没有可用 Windows RDP 主机，未完成真实 Windows 登录后的完整桌面交互验收。
- 未在 Windows 系统执行 ConPTY 或串口驱动测试。
- 桌面美观性包含主观判断；本轮实际核对了常见窗口下的布局、中文标签和长表单，没有声称覆盖全部主题、分辨率及所有外设组合。
- Vite 仍提示远程桌面 WASM 等大资源包；这是构建提示，不是本轮测试失败。

## 复现入口

```sh
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vitest/vitest.mjs run
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
make e2e
```

低磁盘环境的 E2E 可为 runner 设置 `CARGO_PROFILE_DEV_DEBUG=0` 和 `CARGO_INCREMENTAL=0`。新增协议用例位于 `tests/e2e/specs/73-protocol-connections.spec.ts`；它自建回环测试服务，无需真实网络设备。
